# 🖼️ Image Search Engine 🌐  

**Image Search Engine** is an intuitive and powerful tool that allows users to upload an image and receive recommendations for visually similar images from a pre-trained database. The system leverages cutting-edge machine learning technology and is an integral feature of **"Pushp"**, an e-commerce platform dedicated to promoting traditional Indian artisans and handicrafts.  

---

## 🌟 **Key Features**  

- **Image Upload**: Users can upload any image to initiate a search.  
- **Similarity Search**: Recommends similar images from the database trained using a **VGG19** model.  
- **Integrated Experience**: Designed as part of **Pushp**, an e-commerce platform supporting Indian artisans and craftsmen.  

---

## 🛠️ **Tech Stack**  

### **Frontend**  
- **HTML**, **CSS**, **JavaScript**: For a seamless and responsive user interface.  

### **Backend**  
- **Flask**: Handles server-side operations and connects the frontend to the machine learning model.  

### **Machine Learning**  
- **Model**: Pre-trained **VGG19** for feature extraction and image similarity detection.  
- **Library**: Utilizes the **DeepImageSearch** Python library for efficient image retrieval.  

---

## 📥 **How It Works**  

1. **Upload an Image**: Users upload an image via the interface.  
2. **Processing**: The backend processes the image and uses the VGG19 model to extract features.  
3. **Image Retrieval**: Similar images are retrieved from the pre-trained database and displayed to the user.
   
This feature is meant to be **integrated with Pushp**, where recommended images are linked to products on the **Pushp** platform, promoting traditional Indian handicrafts.
